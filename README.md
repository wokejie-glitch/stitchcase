# StitchCase

One intake, every document, a clear case timeline in minutes.

A lawyer's case intake and timeline tool that stitches together multiple technologies: a Next.js web frontend, PostgreSQL, PDF document parsing, calendar reminders, and Claude via Kiro for drafting case summaries.

## How to try it

Open the hosted demo, click Dashboard → Intake → Documents → Timeline → Summary & Export. No login required.

## Built with

Next.js, PostgreSQL, Claude, Kiro, PDF parsing
